## 1. Brief Summary of the App

**Medicore.AI** bridges traditional machine learning classification with generative artificial intelligence. Users select from **132 distinct symptom parameters** to receive instant prognosis predictions generated by a trained Random Forest classifier. A integrated **Google Gemini AI** layer translates structured outputs into plain-English summaries, actionable care steps, and interactive health guidance.

---

## 2. Features List

- 🎯 **Multi-Symptom Input:** Select multiple symptom parameters via an intuitive, responsive frontend UI.
- 🌲 **Random Forest ML Engine:** Evaluates inputs across a 41-class multi-label diagnosis target.
- 🤖 **Contextual Gemini AI Assistant:** Converts structured disease predictions into friendly, human-readable explanations.
- ⚡ **RESTful Flask Backend:** Lightweight WSGI API built for sub-second prediction responses.
- ☁️ **Cloud Native:** Fully containerized production deployment hosted on Render via Gunicorn.

---

## 3. Project Summary

Medicore.AI addresses the fundamental limitation of pure generative AI in healthcare - **hallucinations** - by grounding the output in a deterministic machine learning model.

### **Hybrid Architecture Model**
1. **Deterministic Layer (Random Forest):** Processes 132 binary symptom flags (`0` or `1`) to output candidate prognosis classes.
2. **Generative Layer (Google Gemini):** Adds a layer of intelligence by processing natural language from unstructured input prompts through the chatbot, to provide further context and reasoning.


```

[ User Input ] ---> [ Random Forest (model.pkl) ] ---> [ Predicted Condition ]
|
v
[ Conversational Output ] <--- [ Google Gemini API ] <--- [ Prompt Context ]

```

### **Model Audit & Performance Evaluation**
- **Dataset:** 4,920 rows across 132 symptom features and 41 target prognosis conditions.
- **Accuracy Score:** **`97.62%`** on holdout test set (`data/testing.csv`).
- **Evaluation Strategy:** Monitored using `classification_report` in `notebooks/explore_data.py` to audit **Precision**, **Recall**, and **F1-Scores** across rare and common conditions.

## 🚀 8. How to Run Locally

### 1. Clone the Repository

```bash
git clone [https://github.com/IAmLegendX9/symptom-detector](https://github.com/IAmLegendX9/symptom-detector)
cd symptom-detector

```

### 2. Set Up Virtual Environment

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate

```

### 3. Install Dependencies

```bash
pip install -r requirements.txt

```

### 4. Configure Environment Secrets

Create a `.env` file in the project root:

```env
GEMINI_API_KEY=your_actual_gemini_api_key_here

```

### 5. Train & Audit Model (Optional)

```bash
python notebooks/explore_data.py

```

### 6. Launch Application

```bash
python app.py

```

Open your browser and go to `http://127.0.0.1:5000`.
